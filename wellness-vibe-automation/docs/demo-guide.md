# Demo Guide

Use synthetic data and staging credentials.

1. Start with the case-study README and show the runtime split.
2. Open the n8n orchestrator export and identify account filtering, platform routing, collector handoffs, and failure monitoring.
3. Walk through the payment reminder source and explain the separate WhatsApp/email idempotency keys.
4. Walk through Voice Clarity retrieval to master synchronization and point out all-time snapshot behavior.
5. Submit a dry-run campaign request and show campaign, recipient, job, and execution-log transitions.
6. Show the field map and security notes before discussing deployment.
7. Close with the validation gap: the public repository contains architecture and implementation source, not evidence of live credentials, delivery, or measured outcomes.
